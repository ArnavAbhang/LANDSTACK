# LAND STACK — 10 Parcel Sample Dataset

This package contains 10 sample Maharashtra parcel records structured for the
LAND STACK SIH26014 prototype.

Coverage includes:
- Cadastral parcel geometries and ULPINs
- Maharashtra 7/12, 8A and Ferfar records
- Registration and mutation
- Property tax and utilities
- Land use, zoning, master-plan and restriction layers
- Roads and utility networks
- Disputes and document consistency
- AI risk scenarios
- Canonical parcel records

GIS CRS: EPSG:4326.

The records are sample data for prototype demonstration and should not be
represented as official government records.
